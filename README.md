# Luxury Girl

Приложение для Android и Windows с каталогом топовых казино и покер-румов с рейкбеком. Ссылки на площадки обновляются автоматически при блокировке домена — рабочий вход всегда под рукой, искать новое зеркало вручную не нужно.

## Зачем это нужно

Домены казино и покер-румов регулярно блокируют, а искать актуальный рабочий адрес через поисковики или мессенджеры с каждым разом сложнее — в выдаче много дорвеев и старых обзоров, которые никуда не ведут. Luxury Girl решает эту проблему: приложение хранит каталог проверенных площадок и само подставляет рабочую ссылку, если старый адрес перестал открываться.

## Что в каталоге

- **Топ** — казино с самой активной аудиторией прямо сейчас, лицензированные операторы с честными выплатами.
- **Новинки** — недавно добавленные площадки с актуальными приветственными бонусами.
- **Покер** — покер-румы с рейкбеком и живыми турнирами, вынесены отдельно от слотовых казино.
- **Крипта** — казино с приёмом оплаты в криптовалюте, пополнение и вывод без привязки банковской карты.

## Как начать

1. Скачайте APK для Android или установщик для Windows по ссылкам ниже.
2. Разрешите установку из неизвестных источников — это стандартное системное предупреждение, не признак проблемы с файлом.
3. Откройте приложение, выберите раздел каталога и переходите по рабочей ссылке.

Регистрация в самом приложении не нужна — она нужна только на стороне выбранного казино, если вы решите играть.
