# Luxury Girl

Приложение для Android и Windows с каталогом топовых казино и покер-румов с рейкбеком. Ссылки на площадки обновляются автоматически при блокировке домена — рабочий вход всегда под рукой, искать новое зеркало вручную не нужно.

**Сайт:** https://luxurygirl.online/
**Каталог казино:** https://luxurygirl.online/#catalogue
**Скачать APK (Android):** https://luxurygirl.online/luxury-girl.apk
**Скачать EXE (Windows):** https://luxurygirl.online/luxury-girl-setup.exe

Регистрация не нужна — переход по ссылке из каталога сразу ведёт на выбранное казино или покер-рум.
